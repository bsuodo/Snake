# Over mijzelf
Ik ben Amin, opdracht aandacht het maken voor deltion zwolle.

Dit wordt mijn eerse project, dus dacht ik laat ik met iets makkelijk beginnen. Snake, een heel simpel spel, als dat te makkelijk wordt en als ik wat tijd over heb zou ik het mezelf wat moeilijker te maken door multiplayer toe te voegen met verschillende gamemodes.

Linux en Windows zijn de platformen die ik voor kan bouwen, je kan dan na de eind datum gemmakelijk het programma downloaden, anders moet je het zelf gaan bouwen.

Het spel snake is open domein dus ik kan het gewoon gebruiken, zolang het maar geen snake heet. Met snake bedoel ik het project, maar het spel zelf krijgt een andere naam. Die naam krijg je te zien na het eind datum.

Ik neem aan dat ik niet hoef uit te leggen hoe snake werkt. Iedereen kent het. In het geval ik vast loop zijn er meer dan genoeg 'tutorials' online beschikbaar.

Dit Programma gebruikt geen data, dus stel je gerust.

Deze project valt onder de MIT licentie, dat houdt in dat je alles mag doen wat je ermee wilt zolang je de MIT licentie in de root project behoudt. Wil je specifiek weten wat de licentie ingoudt zie project root folder.

Ik zal een week over doen, vanaf donderdag 24 september t/m donderdag 1 oktober.

Binnen die tijd wil ik leren hoe je alles stukken code samenbrengt, denk aan botsing, geluid effecten, networking (extra), input en nog veel meer.

**Ik waarschuw je alvast**. Het spelletje gaat er niet mooi uit zien, in de middelbare school heb ik nog net een voldoende gehaald.
